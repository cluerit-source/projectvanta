# Vanta

### [Download Vanta for Windows](https://github.com/cluerit-source/projectvanta/releases/latest)

Open the latest release and download the **Vanta Windows installer** (`Vanta_*_x64-setup.exe`). Run the installer, then open Vanta from the Start menu.

If no release is listed yet, the installer has not been published. The launcher checks for signed updates automatically after installation.
